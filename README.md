# 游戏开发辅助工具

使用 **Godot 4.6 .NET 原生 UI** 开发的独立 Windows 工具套件。主界面左侧为功能导航，右侧为工作区。沿用 DesktopTool 的白色侧栏、浅灰工作区和蓝色强调色，不依赖 Qt、WebView 或网页前端。

当前集成 **关卡布局矢量工具、物品配置工具**，并提供项目管理、最近工程、设置和使用指南。物品模块使用 Godot 原生控件，日常运行不依赖原 ItemStudio 或 Qt。

现已增加按功能分类的 **MCP 服务**，支持 AI 读取、绘制、修改关卡及获取 PNG 图像，并提供独立的物品配置分类。打开左侧“MCP 服务”启动并复制客户端连接配置，详见 [MCP使用说明.md](MCP使用说明.md)。

## 启动

- 已构建独立版本：运行 `dist/游戏开发辅助工具.exe`。
- PowerShell 7：运行 `./启动.ps1`，优先启动独立版本。
- 编辑工程：使用 Godot **.NET** 版导入 `project.godot`，或运行 `./启动.ps1 -Editor`。
- 普通非 .NET 版 Godot 无法加载本项目的 C# 业务程序集。

## 语言分工

| 层 | 语言 | 实际职责 |
| --- | --- | --- |
| 几何计算 | C++20 | 批量命中测试、包围盒粗筛、边投影、支持自交面的奇偶填充剖分、连续虚线细分 |
| 业务和编辑 | C# / .NET 8 | 项目模型、兼容读写、撤销重做、编辑交互、属性面板、文件锁和导出 |
| 简单界面辅助 | GDScript | 原生 UI 主题与样式配置 |

C++ 编译为 `level_geometry.dll`，C# 通过窄 C ABI 批量调用。没有把 Qt 引擎或 Qt 窗口嵌入 Godot，也不需要额外下载 godot-cpp。接口版本在启动时检查；缺少本地库会明确报错。

## 关卡功能

- 点集、连续折线、多边形、逐点创建、红色节点拖动、对象移动、插入/删除节点。
- 绿化、农田、山地、沙漠、森林、普通平原、道路、家具、水域、建筑、刷怪点、NPC、移动路线。
- 面纹样、圆角道路及中心虚线、专用矢量标记、对象名称。
- 对象列表、层级、复制、填充/轮廓颜色、尺寸、节点坐标。
- 常用角吸附、最小角倍数、标尺、十字线、分级网格、中键平移、鼠标中心缩放。
- 完整操作撤销重做、草稿取消、关闭前未保存确认。
- 原生 PNG 导出、带分组/图例/预设/名称/工程元数据的 SVG 导出。

长度数据按米保存，界面显示两位小数；内部保留旧文件的双精度坐标，不因显示精度强制舍入原数据。旧工程的厘米/千米显示设置会保留在文件中，新界面统一显示米。

## 物品配置

左侧“物品配置”提供物品配置、词条配置、资源管理三个视图：

- 按分类和名称搜索，新增、复制、编辑、删除物品或词条。
- 编辑价格、堆叠、稀有度、说明、图标、装备词条、倍率、生效间隔及制作配方。
- 按真实类型编辑导入的业务参数，包括增益、技能、属性影响和资源恢复；保留 `source`、`sourceRecord` 及其他扩展字段。
- 分类新增、改名、删除；记录可拖到分类树中移动。被引用的记录、非空分类和内置分类受保护。
- 图标多选导入、内容去重、缩略图缓存、原图查看和图标引用选择。
- Ctrl+S 保存当前配置；切换记录、功能或关闭前处理未保存草稿。

当前工作数据位于 `数据/物品配置/`，使用原 ItemStudio 的 `schemaVersion: 1` 格式。首次迁移包含 **450 个物品、471 个词条、189 个图标记录、23 个角色属性**；354 个文件逐一比较 SHA-256。原配置、上一版备份、原始快照、导入报告、原图和缩略图均已复制。`迁移报告.json` 保存来源与逐文件校验信息。原 ItemStudio 目录保持不变，两个目录之后独立编辑，不会自动双向同步。

每次保存增加修订号，同目录临时文件通过原子替换落盘，上一版保留为 `配置.json.bak`；`.工作区锁` 与 Qt 原工具兼容。外部改动会阻止覆盖，校验失败保留草稿。备份或交接必须复制整个数据目录，不能只复制配置 JSON。

开发运行与当前 `dist` 程序共用工程根目录下的迁移数据。独立分发时，将整个 `dist/` 与 `数据/` 放在同一父目录，也可以将 `数据/` 放到 EXE 所在目录；页面支持“打开数据目录”，命令行支持 `--item-data <绝对目录>`。发布构建不会覆盖现有工作数据。

```powershell
./验证.ps1 -Items           # 临时副本验证保存、锁、引用、配方、图片导入与物品 MCP
./验证.ps1 -Items -Visual   # 同时生成 build/验证/物品配置.png
```

`迁移物品数据.ps1` 用于首次迁移，目标目录已存在时拒绝覆盖；不复制源程序的运行锁，也不会删除源数据。
## 数据兼容

直接打开 DesktopTool 的 `.level.json`，格式标识 `DesktopTool.LevelLayout`、版本 `1`。保留 ID、对象顺序、类型、预设、顶点、透明度、宽度、直径及辅助设置。颜色显式处理 Qt `#AARRGGBB`。

SVG 是输出格式；继续编辑时使用 `.level.json`。当前不提供任意外部 SVG 的导入编辑。

保存先写同目录临时文件再原子替换。`项目路径.lock` 与旧工具使用同名文件；文件被占用时拒绝打开，保存失败不丢弃当前工作区。程序异常退出可能留下侧车锁，确认没有其他进程编辑后可以手动删除。当前对历史锁采用保守处理，不自动猜测并删除。

首次运行显示可编辑的海滨街区示例，不自动写入用户项目。工程保存在用户指定位置；设置及最近文件存放于 Godot 的独立用户目录，可从“设置”打开。

## 缓存与性能

- 每个矢量对象一个可复用显示节点，鼠标移动不重新绘制整张关卡。
- 画布背景、正式对象、草稿及交互手柄分层；视口缩放平移复用对象网格。
- 对象编辑时只重建受影响对象；纹样贴图全局共享；虚线细分及面剖分结果缓存。
- 命中测试使用本地场景及包围盒粗筛；不为每个顶点创建节点，不启用物理碰撞。
- 支持低处理器占用模式；无编辑时不运行每帧业务循环。
- 当前通用奇偶剖分算法对复杂自交图形仍有二次方级计算成本；超大型关卡应依据真实数据继续做空间索引和异步几何优化，不能视为无限规模保证。

## 构建和验证

依赖：Godot 4.6 .NET、.NET SDK 8 或以上、Visual Studio C++ 桌面工作负载、CMake 3.24 或以上。

```powershell
./构建.ps1
./验证.ps1
./验证.ps1 -Visual
./构建.ps1 -Export
```

本机引擎位于 `.tools/`；此目录及构建输出不纳入版本控制。独立导出需要 Godot 4.6 .NET Windows 模板。输出目录 `dist/` 必须整体分发，不能只复制 EXE。

验证覆盖 JSON/ARGB 兼容、C++ 凹面及自交面剖分、拾取、工程锁、保存点历史、实际鼠标输入、SVG 元数据；图形验证额外导出 PNG 并生成主界面截图，放在 `build/验证/`。

新工具增加独立业务类和页面，通过统一导航进入；不要给未实现功能添加无法使用的占位入口。

## 本机验证记录（2026-10-30）

- C++ Release 与 C# 编译成功，C# 无警告、无错误。
- Godot 4.6 .NET 无界面核心检查通过；实际 Vulkan Mobile 图形模式下 PNG/SVG 导出和界面截图检查通过。
- Windows 独立导出版本已通过核心检查和图形启动检查，正常退出码为 0。
- 本机 C++ 几何微基准：1,024 个对象、10,000 次拾取合计约 6.01 毫秒；1,024 顶点多边形剖分约 2.64 毫秒。结果仅反映该固定数据集和本机几何计算，不等同于端到端帧率。
- 示例文件：`示例/海滨街区.level.json`。主界面默认载入同类示例，供首次体验。
- 默认使用 Mobile 渲染器与 2D MSAA；界面标签采用 MSDF 字体，并在缩小时保持可读字号。
